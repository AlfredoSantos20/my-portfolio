# Alfredo Santos — Personal Portfolio Website 🚀

This is a responsive, animated portfolio website built using **React** and **Vite**, showcasing my projects, services, contact info, and professional background. It features smooth transitions with [Framer Motion](https://www.framer.com/motion/) and AOS for animation, and follows a clean modern UI using Tailwind CSS.

## 🚀 Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- [React Icons](https://react-icons.github.io/react-icons/)

## 💼 Features

- Fully responsive design for all screen sizes
- Smooth scroll and animation transitions
- Projects section with tab filter
- Services and About sections
- Contact form with external links
- Social media integration (LinkedIn, GitHub, Facebook, Instagram, X)
- Back to top button

## 🔧 Setup Instructions

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
