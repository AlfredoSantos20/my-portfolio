# 🌐 Alfredo B. Santos Jr. — Personal Portfolio

A modern, responsive, and animated portfolio website built to showcase my work, skills, and professional experience as a Fullstack Developer.

🔗 **Live Demo:** https://alfredo-santos.vercel.app/

---

## 🚀 About

This portfolio highlights my development journey, featuring selected projects, services, and ways to connect with me.

It focuses on:

* Clean and modern UI/UX
* Smooth animations and interactions
* Performance and responsiveness

---

## 🛠️ Tech Stack

* ⚛️ React (Vite)
* 🎨 Tailwind CSS
* 🎞️ Framer Motion
* ✨ AOS (Animate On Scroll)
* 🔗 React Icons

---

## ✨ Features

* 📱 Fully responsive design (mobile → desktop)
* 🎬 Smooth animations and transitions
* 🗂️ Project showcase with filtering
* 🧑‍💼 Services & About sections
* 📬 Contact section with external links
* 🌐 Social media integration
* ⬆️ Back-to-top functionality

## ⚙️ Getting Started

### 1. Clone the repository

```bash
https://github.com/AlfredoSantos20/my-portfolio.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

## 🚀 Deployment

This project is deployed using **Vercel**.
